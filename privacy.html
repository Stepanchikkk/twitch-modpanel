🛡️ Политика конфиденциальности

Twitch ModPanel — панель модератора для Twitch, доступная как расширение для Chrome и как пользовательский скрипт (Tampermonkey). Настоящая политика действует для обеих версий.

Какие данные мы собираем

Мы не собираем и не храним ваши данные на своих серверах. Все данные пользователя обрабатываются локально на вашем устройстве.

Что хранится локально

  • Токен доступа OAuth (tmod_access_token), выданный Twitch для авторизации панели;
  • Информация о пользователе: id, login, display_name;
  • Настройки панели: положение окна, размер, выбранные опции, цвета, история анонсов.

Хранение: расширение использует chrome.storage.local в браузере Chrome; пользовательский скрипт — хранилище Tampermonkey (GM_setValue). Данные не покидают ваше устройство и не синхронизируются с облаком.

Что передаётся и кому

Панель взаимодействует только с официальными API Twitch:

  • id.twitch.tv — авторизация OAuth;
  • api.twitch.tv/helix — запросы модерации (список модераторов, шилд-режим, анонсы, инфо о канале, проверка подписок);
  • gql.twitch.tv — внутренние функции Twitch (например, детектор возможных модераторов).

Ваши данные (включая токен) не передаются никаким третьим лицам, кроме Twitch, и только в рамках функций панели.

Файлы cookie

Расширение может читать файл cookie auth-token на сайте twitch.tv — он используется исключительно для обращения к внутренним функциям Twitch через gql.twitch.tv из вашего браузера. Значение cookie не хранится и не передаётся никуда, кроме Twitch.

Реклама и аналитика

Расширение не содержит рекламы, трекеров, аналитики и не собирает статистику использования.

Удаление данных

Все данные можно удалить в любой момент:

  • в настройках панели («Выйти» / «Сбросить токен»);
  • удалением расширения через chrome://extensions (при этом также очищается chrome.storage.local);
  • удалением скрипта в Tampermonkey (очищается хранилище GM_setValue).
